# PikoBlackjack (`blackjack`)

Interactive single-deck Blackjack (Hit/Stand/Double/Split), betting real
PIKO, fully on-chain. Same self-funding/escrow/timelock shape as `dice` in
this repo, different game.

**This canister is deployed as a completely separate icp-cli project**, not
part of piko-icp's own `icp.yaml`/deploy lifecycle -- its source is included
here purely for public code transparency, matching this project's own
verify-it-yourself ethos. See the root `README.md`'s canister table for
mainnet ids and URLs.
